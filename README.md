# Olá, eu sou Jeisson Rocha da Cunha

### Analista de Sistemas | Desenvolvedor Full Stack | Especialista em Banco de Dados

Profissional de Tecnologia da Informação com mais de **17 anos de experiência** em análise de sistemas e desenvolvimento de soluções web, desde websites até sistemas empresariais.

Sou diretor e proprietário da **Air Tecnologia**, onde construí uma trajetória que reúne desenvolvimento de software, análise de requisitos, banco de dados, liderança de equipes, gestão de projetos e relacionamento com clientes.

Minha experiência principal foi construída com **PHP e MySQL**. Atualmente, estou ampliando minha stack com **React, Node.js e Tailwind CSS**, mantendo o foco na criação de soluções completas, do Front-end ao Back-end.
