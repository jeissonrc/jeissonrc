# Olá, eu sou Jeisson Rocha da Cunha

### Analista de Sistemas | Desenvolvedor Full Stack | Especialista em Banco de Dados

Profissional de Tecnologia da Informação com mais de 18 anos de experiência em análise de sistemas, desenvolvimento de software e evolução de soluções web e empresariais. Gosto de entender o problema, organizar os requisitos e transformar necessidades de negócio em soluções úteis.

Sou cofundador e diretor da **Air Tecnologia**. Minha trajetória reúne desenvolvimento de software, levantamento de requisitos, bancos de dados, gestão de projetos e relacionamento com clientes. Ao longo dos anos, trabalhei tanto na construção de sistemas sob medida quanto na evolução de soluções utilizadas em contextos reais.

Minha experiência consolidada inclui PHP, MySQL, JavaScript, C# e SQL Server. Em projetos mais recentes, venho trabalhando com React, TypeScript, Node.js, APIs REST e Flutter, além de explorar automação e aplicações de Inteligência Artificial.

## Projetos em destaque

### BRazucaFlow — Gestão financeira

Projeto de conclusão de ADS: uma aplicação web de gestão financeira voltada a pessoas e pequenos negócios, com contas a pagar e receber, receitas, despesas, plano de contas, relatórios, auditoria e diferentes níveis de acesso.

**Tecnologias:** React, TypeScript, Tailwind CSS, Node.js, Express, Sequelize, MySQL e API REST.

- [Aplicação online](https://brazukaflow.com.br/)
- [Documentação da API](https://api.brazukaflow.com.br/docs)
- [Frontend](https://github.com/jeissonrc/brazukaflow_front_app)
- [API](https://github.com/jeissonrc/brazukaflow_api)

### Flutter Rick and Morty App

Aplicação mobile desenvolvida com **Flutter e Dart**, integrando Firebase Authentication e a Rick and Morty API. Explora autenticação, consumo de API REST, filtros, paginação, detalhes de personagens e navegação por localizações e dimensões.

- [Repositório](https://github.com/jeissonrc/flutter-rick-and-morty-app)

### Agro4Business — Discovery de produto

Case acadêmico de pesquisa, discovery de produto, UX e prototipação de alta fidelidade para uma solução digital voltada ao produtor rural. O trabalho envolveu pesquisa, personas, identificação de necessidades, priorização, wireframes e protótipo.

- [Repositório](https://github.com/jeissonrc/agro4business-product-case)

### Pitfall Clone

Jogo experimental para navegador, inspirado no clássico *Pitfall!*, desenvolvido com HTML, CSS, JavaScript e HTML5 Canvas. Explora loop de jogo, colisões, movimentação, obstáculos, inimigos, pontuação, vidas e diferentes cenários.

- [Repositório](https://github.com/jeissonrc/pitfall-clone)
- [Jogar online](https://jeissonrc.github.io/pitfall-clone/)
